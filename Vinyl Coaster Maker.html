Vinyl Coaster Maker

Upload an image, get print-ready multicolor STL files. Coaster Ø100 × 3 mm, black rim, sealed NFC cavity (pause the print and insert the tag), image on both faces.

Or upload a font file (.ttf, .otf, .woff)
Scroll or pinch to zoom, drag to move the image.
  1. Import all STLs into the slicer together, keep their positions, and assign one filament per file.
  2. base_black is the black body and rim, with the sealed cavity inside. Each color_* file holds that color on both faces.
  3. The underside is mirrored so it reads correctly when the coaster is flipped like a page.
  4. Schedule a pause at the Z height shown above, which is the top of the cavity and just before the ceiling prints. Drop the tag in flat, then resume. The ceiling bridges the cavity, so no supports are needed.
  5. With text on, it is inlaid into the rim: text_*.stl is the text color and sits in the same layers as the black rim, so it needs its own filament.
